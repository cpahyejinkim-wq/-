# Limitations

## Phase 1 (현재)

### 데이터
- **전종목 미지원**: MockProvider는 샘플 5종목만 지원. 실사용 시 Phase 2 실 프로바이더 필요.
- **실시간 미지원**: 가격 데이터는 분석 시점에만 갱신. 실시간 호가/체결 없음.
- **재무 데이터 합성**: 영업이익·매출 성장률은 MockProvider 고정값. 실제 DART 공시와 무관.
- **테마/섹터 매핑 고정**: 피어 종목명은 하드코딩. 실제 KRX 섹터 분류 미연동.

### 엔진 정확도
- **패턴 감지는 규칙 기반**: T바닥·포킹 등은 구현된 휴리스틱 규칙의 결과이며 머신러닝 기반이 아님. 유사하지만 다른 패턴을 놓치거나 잘못 분류할 수 있음.
- **단계 분류 경계 노이즈**: 포킹/펌핑 경계처럼 연속 변수를 이진 분류하는 과정에서 오분류 발생 가능.
- **멀티 타임프레임 신뢰도**: 과거 이력이 짧은 신규 상장 종목은 월봉 MA 계산 불가 → 점수 과소.

### 거래 계획
- **지지/저항선은 근사치**: 피벗 알고리즘(fractal highs/lows)은 시장 참가자가 실제로 보는 레벨과 다를 수 있음.
- **ATR 기반 손절 = 참고값**: 실제 손절은 차트 구조·종목 특성·계좌 규모에 따라 개인이 재조정 필요.
- **거래 수수료·슬리피지 미반영**: 제시 가격은 이론적 레벨이며 실제 체결과 차이 발생.

### 법적 고지
- 본 도구는 교육 및 분석 참고 목적이며, **투자 권유가 아닙니다**.
- 실제 투자 결정은 본인의 판단과 책임 하에 이루어져야 합니다.

## Phase 2 계획 시 추가 고려사항
- pykrx 스크래핑 차단 위험 → 공식 KRX 데이터 API 병행 검토
- DART API 호출 한도 (일 10,000건) → 배치 캐싱 필요
- 뉴스 감성 분석 → 한국어 특화 NLP 모델 (KoBERT 등) 연동
- 백테스트 엔진 (`/api/backtest`) — Phase 2에서 구현 예정
